# HackerRank Problem Solving

Welcome to my daily HackerRank problem-solving repository! This space serves as a log of my coding journey, where I tackle algorithmic and data structure challenges daily to sharpen my problem-solving skills.

---

## 📂 File Naming Conventions

To keep the repository clean, structured, and easy to navigate, all solution files follow a strict naming convention and organized on folders based on category and languages:

```text
[problemName].[ext]
```

*   **`[problem-slug]`**: The hyphenated lowercase name of the problem as it appears in the HackerRank URL (e.g., `SolveMeFirst`, `AthleteSort`).

## ⚡ Git Commit Workflow

I maintain a consistent and minimal commit history for every problem I complete. Once a solution is tested and verified, I use the following Git workflow:

1. Stage all changes:
   ```bash
   git add .
   ```
2. Commit with the standard completion message format:
   ```bash
   git commit -m "[Problem Name] Completed"
   ```
3. Push the changes to the remote repository:
   ```bash
   git push origin main
   ```
