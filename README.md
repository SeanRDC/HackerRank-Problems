## About

This repository collects my solutions to HackerRank challenges. I work through algorithm, data structure, and language-proficiency problems regularly to sharpen my problem-solving skills, and every solution I complete lands here.

Each file holds one finished solution and opens with a short comment describing how the code works.

## File Naming Convention

Solutions are organized into folders by language and category, and each file is named after its problem:

```text
[ProblemName].[ext]
```

For example, `SolveMeFirst.py` or `DiagonalDifference.py`.

## Git Commit Workflow

I keep a consistent, minimal commit history. Once a solution is tested and verified:

```bash
git add .
git commit -m "[Problem Name] Completed"
git push origin main
```
